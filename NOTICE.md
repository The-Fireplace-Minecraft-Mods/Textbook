Notable changes for the NeoForge port:
- Removed dependencies on Fireplace Lib and Annotated DI (Fabric-only libraries).
- Replaced Fabric entrypoints with NeoForge @Mod entrypoints.
- Reimplemented file dialogs using Swing JFileChooser.
- Reimplemented config persistence using NeoForge ModConfigSpec.
- Ported Mixins from Yarn intermediary mappings to Mojang mappings.
